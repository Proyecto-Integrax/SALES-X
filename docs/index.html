Cómo ejecutarla

git clone https://github.com/Proyecto-Integrax/SALES-X.git
cd SALES-X
bash iniciar.sh        # Linux/macOS  ·  iniciar.bat en Windows
Abre http://localhost:8000 con base SQLite y 40 pedidos de demostración. API interactiva en /docs.
